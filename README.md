
# 메크 서바이벌 (Mech Survival)

## 프로젝트 소개
*본 프로젝트는 한양대학교 ERICA 캠퍼스 산학연계 캡스톤으로 만들어진 졸업작품입니다.*

 - 1인칭으로 즐기는 뱀서라이크. 
 - 친구에게 등을 맡기는 전장.

 **메크서바이벌**은 FPS로 진행되는 뱀서라이크 게임입니다. 유니티 넷코드를 이용한 2인멀티를 지원합니다.
 사방에서 몰려오는 적들을 격파하는 쾌감을 느낄 수 있으며, 강해져가는 느낌을 확실히 받을 수 있습니다.

## 개발정보
- 개발기간: 2026.05.08~2026.06.07 1개월
- 사용기술: Unity, Netcode for GameObjects

### 멀티플레이 구조
- 호스트,클라이언트 방식으로 호스트가 서버를 겸함.
- 서버가 게임의 각종 요소를 관리하는 Manager들을 소유. *단, 클라이언트의 볼륨을 관리하는 SFX매니저는 각자 소유*
- 탄환, 적, 경험치, 드롭 포드의 공용 요소는 서버가 관리. 누적 경험치도 서버가 관리.
- 플레이어 캐릭터, 개인 소유 무장은 개별 조작을 허용해야하기에 클라이언트가 관리.

### 무기 시스템
- WeaponBase라는 추상 클래스를 구현. 해당 클래스는 무기 정보, 무기 레벨, 데미지 산출, 무기 초기화를 소유. 이를 통해 해당 요소를 공통화.
- 무기는 해당 클래스를 상속받아 개인의 작동 방식과 레벨별 효과를 오버라이드해서 구현.
- 이를 통해 기본무기를 제외한 7종의 무기를 구현.
- 플레이어가 소지한 무기를 WeaponController가 자식으로 보유, 관리함.
- 동시에 제거할 수 없으며 필수요소기에 플레이어의 기본 무기도 WeaponController가 겸함.
```
Player
└ WeaponController (관리 + 기본 무기)
    └ RailgunWeapon, OrbitalDroneWeapon, BladeDrone ...
```

### 난이도 설계
- 목표 시간을 변수로 받고 경과 시간을 0~1로 정규화. 시간에 따라 적의 구성, 체력을 수식으로 조절. 경과 시간 비율에 따른 통합관리.
